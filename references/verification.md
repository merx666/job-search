# 验证范围

## 可复现离线检查

需要 Python 3.10+、`requirements.txt` 中的依赖，以及 Node.js 22：

```bash
python -m unittest discover -s tests -v
node --test tests/test_collect.cjs tests/test_page_state.cjs
python job_search.py demo --out /tmp/job-search-demo
python build_package.py --out /tmp/job-search-release
```

CI 在 Python 3.10 / 3.12 上执行这些检查。离线测试使用合成岗位和模拟浏览器，不访问招聘网站。

Python 回归覆盖计划确认、岗位方向授权、逐平台配额、独立查询与详情预算、薪资单位、发布时间与刷新分离、未知信息、证据来源、去重、HTML / Excel 注入防护、空报告、安装冲突、发布白名单、浏览器互斥锁及传输完整性。

预算回归另覆盖按规模生成上限、保留旧计划确认值、显式扩容、不接受无计数的预算耗尽、结果页耗尽后继续详情、详情耗尽后继续结果页、已访问候选去重，以及每组查询先读一页再交给 worklist。加载重读和实际详情读取由宿主 Agent 执行，离线测试不证明真实网站成功率提高。

Node 回归覆盖 BOSS / 猎聘响应映射、真实登录墙与未知身份的区分、平台限流、页面置空后的证据保留、临时页清理及用户标签保留。模拟测试通过不代表平台在线成功率。

## 在线行为的已知边界

- 历史 macOS 检查覆盖过部分 BOSS 搜索路径、登录阻塞、标签复用与临时页清理；没有完成五个平台登录后的完整端到端验收。
- 平台可能将自动化新页面置空。实现优先复用已有用户标签，对页面操作设置限时，保留已捕获的岗位证据；连续未取得响应时暂停该平台。冷却时长是建议，无法保证恢复。
- 用户标签上的全部导航方式、不同账号、不同地区和平台改版后的行为，未逐一验证。
- 脉脉、智联、前程无忧、鱼泡、实习僧的界面流程有操作手册；不等于每个平台都有固定自动采集适配器。
- Windows / Linux 路径有处理，尚未完成系统实机端到端验收。
- 模型配额由宿主管理。浏览器互斥锁不能约束宿主之外的任意工具调用，也不能消除账号侧模型限流。

维护平台适配时，记录入口、访问状态、查询条件和覆盖页数即可；不把用户简历、真实清单、Cookie 或完整运行日志提交到公开仓库。缺少岗位证据时保留“待核实”，不推断发布日期或录用概率。
